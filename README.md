# 英语备考训练台

一个纯静态的英语备考练习站：**12 场考试、12 种题型**，浏览器打开就能用，
不需要注册、没有服务器、没有数据库。

**在线使用**：<https://english-exam-trainer-9tn.pages.dev/>

备用入口（同一份内容，主地址打不开时用）：
<https://zhouxuan078-max.github.io/english-exam-trainer/>

## 12 场考试

| 分类 | 考试 |
|---|---|
| 大学 | 大学英语四级 · 大学英语六级 · 英语专业四级 · 考研英语 |
| 出国 | 雅思 · 托福 · 多邻国 · PTE · GRE · SAT |
| 职场 | BEC（初 / 中 / 高）· 托业 |

先选你要考的那一场，之后首页、题型、进度都只按那一场算 ——
不会出现"背的单词是四级的、练的题是雅思的"这种混用。

## 12 种题型

仔细阅读 · 长篇匹配 · 选词填空 · 填空题 · 单项选择 · 判断题 ·
听力理解 · 听力听写（专四级） · 数学（GRE / SAT 数量推理） ·
写作 · 翻译 · 口语

每场考试按**官方试卷结构**裁剪：比如四级是
「写作 + 听力理解 + 选词填空 + 长篇匹配 + 仔细阅读 + 翻译」，
GRE 有数学，雅思有判断题和口语，专四有听写。

## 其它功能

| 模块 | 说明 |
|---|---|
| 生词本 | 阅读时点单词即查释义（离线词典 5662 词），一键导出成 Anki 能导入的文件 |
| 错题本 | 答错自动记下来，可回看、可清空 |
| 打卡 | 每天练了多少，首页一眼看到 |
| 我的题目 | 自己手上的卷子可以用 AI 转成它认的格式导进来，只存在本机浏览器 |

## 数据从哪来

- **站内题目与样卷：全部原创。** 按各考试的官方卷面结构与难度自行撰写，
  每条内容都标注了 `source.license = 原创`。
  四级用的是一套「站内示例题」，另外 11 场考试各有一份原创样卷。
- **开源词表**：离线词典来自
  [KyleBing/english-vocabulary](https://github.com/KyleBing/english-vocabulary)
  （BSD 3-Clause 许可）。
- **不含真题**：各考试的真题版权分别属于其主办机构，网上流传的题库均无开源许可。
  本站不收录真题，只放自己写的内容。
  （想练真题的话，把卷子用站里的「我的题目 → 加新卷子」导进来，
    只存在你自己浏览器里，不会上传到任何地方。）

## 部署

纯静态站，把仓库根目录丢给任意静态托管即可（现在跑在 GitHub Pages）。
已放 `.nojekyll`，GitHub Pages 不会用 Jekyll 处理。

## 隐私

所有学习进度（错题、生词、打卡、导入的卷子）都存在**你自己浏览器本地**
（localStorage / IndexedDB），不上传任何服务器，也不收集任何用户数据。
换浏览器或清缓存会丢失进度。
