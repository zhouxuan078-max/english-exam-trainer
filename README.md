# 四级训练台

一个纯静态的英语四级练习站：阅读三题型 + 听力听写 + 生词本 + 错题本。
双击 `index.html` 就能用，不需要服务器、不需要数据库、不需要联网（词库和题库都在仓库里）。

## 内容

| 模块 | 说明 |
|---|---|
| 仔细阅读 | 4 篇，每篇 5 题单选，14.2 分/题（对齐真题分值） |
| 长篇匹配 | 分段长文 + 句子配段，7.1 分/题 |
| 选词填空 | 10 空 + 15 个备选词，3.55 分/题 |
| 听力听写 | 浏览器朗读一句，你打出来，自动比对 |
| 生词本 | 阅读时点单词即查释义（离线词典 5662 词），一键导出给 Anki |
| 错题本 | 答错自动记录，可回看可清空 |

## 数据从哪来

- **开源语料**：选词填空 18 篇 + 听力 60 句，取自
  [Project Gutenberg](https://www.gutenberg.org/)（公有领域），由程序自动生成题目，
  每篇都标注了原书编号与链接。
- **原创题目**：仔细阅读与长篇匹配为按四级难度和体裁自行编写
  —— 因为四级考说明文，而目前可访问的开源文本要么体裁不符、要么过难。
- **开源词表**：离线词典来自
  [KyleBing/english-vocabulary](https://github.com/KyleBing/english-vocabulary)
  （BSD 3-Clause 许可）。
- **不含真题**：四级真题版权属教育部教育考试院，网上流传的题库均无开源许可，
  未收录。

## 难度怎么保证

用 NGSL 词频表 + 四级词表计算「词汇覆盖率」。先给自写的四级题打分为标尺
（实测 70.8%～79.0%，中位 77.1%），据此把开源语料筛在 72%～86% 区间，
入选的 18 篇实际落在 77.6%～85.4%，与四级同档。

## 部署

纯静态站，把这个仓库直接丢给任意静态托管即可。
仓库根目录已放 `.nojekyll`，GitHub Pages 不会用 Jekyll 处理。

## 说明

所有学习进度（错题、生词、打卡）都存在**你自己浏览器本地**（localStorage），
不上传任何服务器，也不收集任何用户数据。换浏览器或清缓存会丢失进度。
